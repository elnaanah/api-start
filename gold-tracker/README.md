# حاسبة أسعار الذهب

مشروع تعليمي صغير يوضح كيفية استخدام JavaScript لجلب بيانات من واجهة
برمجة تطبيقات (API)، وإجراء عمليات حسابية عليها، ثم عرض النتائج داخل
صفحة ويب.

## ما الذي يفعله التطبيق؟

يعرض التطبيق سعر أصل الذهب الرقمي `PAXG` مقابل الدولار الرقمي `USDT` كما
توفره خدمة Binance، ثم يستخدم القيمة لتقدير:

-   سعر أونصة الذهب.
-   سعر غرام عيار 24.
-   سعر غرام عيار 21.
-   القيمة الإجمالية لعدد الغرامات الذي يدخله المستخدم، وفق العيار
    المختار.

> **ملاحظة:** يعتمد المثال على سعر زوج التداول `PAXGUSDT` من Binance،
> وليس على تسعيرة محلية لدى تاجر ذهب. الحسابات تقديرية وتعليمية، وقد
> تختلف عن الأسعار الفعلية بسبب فروق السوق والمصنعية والضرائب والرسوم.

## ملفات المشروع

``` text
├── index.html   # واجهة التطبيق وحقول الإدخال
├── app.js       # جلب السعر وإجراء الحسابات
└── README.md    # شرح المشروع وطريقة تشغيله
```

## كيف تُحسب الأسعار؟

يعتمد الكود على التقريبات والمعادلات التالية:

1.  يفترض المثال أن الأونصة تساوي نحو `31.1` غرام.
2.  **سعر غرام عيار 24** = سعر الأونصة ÷ `31.1`.
3.  **سعر غرام عيار 21** = سعر غرام عيار 24 × (`21 ÷ 24`).
4.  **القيمة الإجمالية** = عدد الغرامات × سعر الغرام للعيار المختار.

هذه المعادلات تقدّم تقديراً حسابياً مبسطاً، ولا تشمل تكاليف البيع أو الشراء
الإضافية.

## شرح `app.js`

### 1. الوصول إلى عناصر الصفحة

يستخدم `document.getElementById()` للوصول إلى عناصر HTML التي تحمل
المعرّفات `ounce` و`g24` و`g21` و`grams` و`karat` و`calc-btn` و`result`.
تتيح هذه المراجع قراءة مدخلات المستخدم وتحديث القيم المعروضة.

### 2. تخزين أسعار الغرام

يُعرّف المتغيران `price24` و`price21` لتخزين السعر المحسوب لكل من عيار 24
وعيار 21 بعد جلب البيانات.

### 3. جلب البيانات من API

تستخدم الدالة `getGoldPrices()` الدالة `fetch()` لإرسال طلب إلى عنوان
Binance التالي:

``` text
https://api.binance.com/api/v3/ticker/price?symbol=PAXGUSDT
```

تُستخدم `await` لانتظار استجابة الطلب، ثم تُحوّل `response.json()`
الاستجابة إلى كائن JavaScript. وتُقرأ قيمة السعر من الخاصية `data.price`.

### 4. حساب أسعار العيارات وعرضها

بعد تحويل السعر إلى رقم باستخدام `parseFloat()`، يقسم الكود سعر الأونصة
على `31.1` لتقدير سعر غرام عيار 24. ثم يضرب الناتج في `21 / 24` لتقدير
سعر غرام عيار 21.

تُستخدم `toFixed(2)` لعرض الأسعار بمنزلتين عشريتين، ويُحدّث `textContent`
النص الظاهر في الصفحة.

### 5. حساب قيمة الغرامات

تقرأ الدالة `calculate()` عدد الغرامات والعيار المحدد. إذا كان العيار
`24` تستخدم `price24`، وإلا تستخدم `price21`. بعد ذلك تضرب سعر الغرام في
العدد المدخل وتعرض الناتج بالدولار.

### 6. تشغيل الدوال

-   يستدعي حدث `load` الدالة `getGoldPrices()` عند تحميل الصفحة.
-   يستدعي حدث `click` الدالة `calculate()` عند الضغط على زر الحساب.
-   بعد جلب السعر، تستدعي `getGoldPrices()` الدالة `calculate()` لعرض
    نتيجة أولية وفق القيم الحالية.

تُستخدم `try...catch` لالتقاط الأخطاء التي تحدث أثناء طلب البيانات أو
معالجتها، وعرض رسالة للمستخدم عند تعذر جلب السعر.

## تشغيل المشروع

1.  احفظ الملفات `index.html` و`app.js` في المجلد نفسه.

2.  افتح `index.html` في متصفح حديث.

3.  إذا لم يعمل الطلب عند فتح الملف مباشرة، شغّل خادماً محلياً من داخل مجلد
    المشروع:

    ``` bash
    python3 -m http.server 3000
    ```

4.  افتح `http://localhost:3000` في المتصفح.

يتطلب جلب السعر اتصالاً بالإنترنت وإمكانية الوصول إلى واجهة Binance API.

## مفاهيم JavaScript التي يشرحها المشروع

-   الوصول إلى عناصر الصفحة باستخدام DOM.
-   جلب البيانات عبر `fetch()`.
-   استخدام `async` و`await` مع الطلبات غير المتزامنة.
-   قراءة استجابة JSON والتعامل مع خصائص الكائنات.
-   تحويل النص إلى رقم باستخدام `parseFloat()`.
-   تنفيذ العمليات الحسابية وتنسيق الأرقام باستخدام `toFixed()`.
-   تحديث محتوى الصفحة عبر `textContent`.
-   التعامل الأولي مع الأخطاء باستخدام `try...catch`.

## تحسينات مقترحة للتعلّم

الكود الحالي مثال تمهيدي؛ ويمكن تطويره بإضافة التحقق من `response.ok`،
والتأكد من أن السعر رقم صالح، ومنع الحساب عند إدخال عدد غرامات غير صالح،
وعرض رسائل منفصلة لأخطاء الاتصال والإدخال.
