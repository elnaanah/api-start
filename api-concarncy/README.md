# مشروع تعليمي: محوّل العملات (Currency Converter)

يشرح هذا المشروع، من خلال تطبيق صغير قابل للتجربة، كيفية استخدام
**JavaScript** لجلب البيانات من واجهة برمجة تطبيقات (**REST API**) ثم
استخدامها في إجراء عملية تحويل العملات. يعتمد التطبيق على خدمة
[Frankfurter API](https://frankfurter.dev/) للحصول على أسعار الصرف.

## 1. ماذا يفعل التطبيق؟

يتيح التطبيق للمستخدم إدخال مبلغ مالي، ثم اختيار العملة الأصلية والعملة
المطلوب التحويل إليها. بعد ذلك، يجلب سعر الصرف المناسب ويعرض المبلغ
الناتج.

يدعم المثال العملات التالية:

-   الدولار الأمريكي (`USD`)
-   اليورو (`EUR`)
-   الليرة التركية (`TRY`)


## 2. التقنيات المستخدمة

-   **HTML5:** بناء عناصر الصفحة وحقول الإدخال، مع ضبط اتجاه المحتوى إلى
    اليمين باستخدام `dir="rtl"`.
-   **CSS3:** تنسيق الواجهة وتصميمها عبر وسم `<style>` المضمّن لتناسب الشاشات المختلفة.
-   **Vanilla JavaScript (ES6+):** قراءة مدخلات المستخدم، وإرسال الطلب
    إلى الخدمة، وحساب النتيجة وعرضها دون الاعتماد على مكتبات JavaScript
    إضافية.
-   **Frankfurter API:** توفير بيانات أسعار الصرف التي يحتاج إليها
    التطبيق.

## 3. ملفات المشروع

``` text
├── index.html   # عناصر الواجهة وحقول إدخال البيانات
├── app.js       # منطق التحويل والاتصال بواجهة API
└── README.md    # شرح المشروع وخطوات تشغيله
```

## 4. التعرّف إلى واجهة المستخدم

تحتوي صفحة `index.html` على العناصر الأساسية التالية:

1.  **حقل المبلغ** (`input#amount`): يحدد المبلغ المراد تحويله.
2.  **قائمة العملة الأصلية** (`select#from`): تحدد العملة التي يبدأ منها
    التحويل.
3.  **قائمة العملة المستهدفة** (`select#to`): تحدد العملة التي يراد
    الحصول عليها.
4.  **زر التحويل** (`button#convert-btn`): يستدعي دالة التحويل عند النقر
    عليه.
5.  **عنصر النتيجة** (`div#result`): يعرض حالة العملية أو المبلغ بعد
    التحويل.

تُستخدم المعرّفات (`id`) للوصول إلى هذه العناصر من JavaScript وربط سلوك
الواجهة بالشيفرة البرمجية.

## 5. كيف تعمل الشيفرة؟

يوضح المثال التالي تسلسل عملية التحويل داخل الملف `app.js`:

``` javascript
// 1. الحصول على عناصر واجهة المستخدم
const amountInput = document.getElementById("amount");
const fromSelect = document.getElementById("from");
const toSelect = document.getElementById("to");
const convertBtn = document.getElementById("convert-btn");
const resultDiv = document.getElementById("result");

// 2. جلب سعر الصرف وحساب المبلغ المحوّل
async function convertCurrency() {
  const amount = amountInput.value;
  const from = fromSelect.value;
  const to = toSelect.value;

  // لا حاجة إلى طلب سعر صرف إذا كانت العملتان متطابقتين
  if (from === to) {
    resultDiv.textContent = `${amount} ${to}`;
    return;
  }

  // إبلاغ المستخدم بأن العملية قيد التنفيذ
  resultDiv.textContent = "جارٍ التحويل...";

  try {
    // إرسال طلب إلى Frankfurter API
    const response = await fetch(
      `https://api.frankfurter.dev/v1/latest?base=${from}&symbols=${to}`
    );

    const data = await response.json();

    // قراءة سعر الصرف وحساب النتيجة
    const rate = data.rates[to];
    const finalResult = (amount * rate).toFixed(2);

    // عرض النتيجة
    resultDiv.textContent = `${finalResult} ${to}`;
  } catch (error) {
    // عرض رسالة إذا تعذّر إكمال الطلب
    resultDiv.textContent = "تعذّر جلب بيانات سعر الصرف. حاول مرة أخرى.";
  }
}

// 3. تنفيذ التحويل عند النقر على الزر وعند تحميل الصفحة
convertBtn.addEventListener("click", convertCurrency);
window.addEventListener("load", convertCurrency);
```

### شرح الأجزاء الرئيسية

**أولاً: الوصول إلى عناصر الصفحة**

تُستخدم `document.getElementById()` للحصول على عناصر HTML اعتماداً على
قيمة `id`. بعد ذلك، يمكن قراءة القيم التي أدخلها المستخدم أو تحديث النص
الظاهر في الصفحة.

**ثانياً: الدالة غير المتزامنة `async`**

تُعرّف `convertCurrency()` باستخدام `async` لأنها تتعامل مع طلب شبكة قد
يستغرق وقتاً حتى تكتمل استجابته. وتسمح `await` بانتظار النتيجة قبل
الانتقال إلى الخطوة التالية، من دون تجميد واجهة المتصفح.

**ثالثاً: إرسال الطلب باستخدام `fetch()`**

يُرسل `fetch()` طلباً إلى عنوان الخدمة (API endpoint). ويحدد معامل `base`
العملة الأصلية، بينما يحدد `symbols` العملة المطلوب معرفة سعرها مقابل
العملة الأصلية. على سبيل المثال:

``` text
https://api.frankfurter.dev/v1/latest?base=USD&symbols=TRY
```

يعني هذا المثال طلب سعر صرف الليرة التركية مقابل الدولار الأمريكي. وتُحدّث
الخدمة أسعارها وفق البيانات المتاحة لديها؛ لذلك لا ينبغي افتراض أن السعر
لحظي أو ثابت.

**رابعاً: قراءة استجابة JSON**

تحوّل `response.json()` محتوى الاستجابة إلى كائن JavaScript. ثم تُقرأ قيمة
سعر الصرف من `data.rates[to]` وتُضرب في المبلغ المدخل للحصول على النتيجة.

تستخدم `toFixed(2)` لعرض النتيجة بمنزلتين عشريتين. وهي تُرجع نصاً
(string)، وهو مناسب للعرض في هذه الواجهة التعليمية.

**خامساً: التعامل مع العملتين المتطابقتين**

إذا كانت العملة الأصلية هي نفسها العملة المستهدفة، يعرض التطبيق المبلغ
كما هو، ولا يرسل طلباً غير ضروري إلى الخدمة.

**سادساً: معالجة الأخطاء**

تتيح `try...catch` التعامل مع بعض الأخطاء التي قد تحدث أثناء الطلب أو
قراءة الاستجابة. في هذا المثال، تظهر رسالة عامة للمستخدم عند تعذّر إكمال
العملية. ولزيادة متانة التطبيق، يمكن في مرحلة لاحقة التحقق من
`response.ok`، والتأكد من صحة المبلغ، ومعالجة غياب سعر الصرف قبل حساب
النتيجة.

## 6. المفاهيم التي يكتسبها المتعلّم

بعد دراسة المشروع وتجربته، يُفترض أن يتمكن المتعلّم من فهم المفاهيم
التالية:

1.  **REST API وEndpoint:** كيفية طلب بيانات من خدمة خارجية باستخدام
    عنوان محدد ومعاملات استعلام.
2.  **`fetch()`:** إرسال طلب HTTP من المتصفح.
3.  **`async` و`await`:** تنظيم العمليات غير المتزامنة وقراءة نتائجها
    بالترتيب.
4.  **JSON:** تحويل بيانات الاستجابة إلى كائن JavaScript والتعامل مع
    خصائصه.
5.  **DOM:** الوصول إلى عناصر HTML وقراءة قيمها وتحديث المحتوى المعروض.
6.  **الحالات الاستثنائية (Edge Cases):** التعامل مع تطابق العملتين،
    والتفكير في حالات الإدخال غير الصحيح أو نقص البيانات.
7.  **`try...catch`:** توفير معالجة أولية للأخطاء بدلاً من ترك العملية
    تفشل دون رسالة واضحة.

## 7. تشغيل المشروع محلياً

لا يحتاج المشروع إلى تثبيت حزم أو إعداد أداة بناء.

### الطريقة الأولى: فتح الصفحة مباشرة

افتح `index.html` في متصفح حديث. إذا واجهت مشكلات مرتبطة ببيئة التشغيل
أو طلبات الشبكة، فاستخدم خادماً محلياً بدلاً من فتح الملف مباشرة.

### الطريقة الثانية: تشغيل خادم محلي

1.  افتح الطرفية داخل مجلد المشروع.

2.  نفّذ الأمر التالي إذا كان Python 3 مثبتاً لديك:

    ``` bash
    python3 -m http.server 3000
    ```

3.  افتح العنوان التالي في المتصفح:

    ``` text
    http://localhost:3000
    ```

## 8. ملاحظات قبل تطوير المشروع

الكود المعروض مصمم للتعلّم، ويمكن تحسينه بعد التأكد من فهم آلية عمله. من
التحسينات المفيدة:

-   التحقق من أن المبلغ رقم صالح وأكبر من أو يساوي الصفر.
-   فحص `response.ok` قبل محاولة استخدام بيانات الاستجابة.
-   التأكد من وجود سعر الصرف المطلوب قبل إجراء عملية الضرب.
-   عرض رسالة مختلفة عند وجود إدخال غير صالح أو عند تعذّر الاتصال
    بالخدمة.
-   إظهار تاريخ أسعار الصرف أو مصدرها للمستخدم، إذا كانت واجهة الخدمة
    توفر هذه المعلومات.

تساعد هذه التحسينات على الانتقال من مثال تعليمي بسيط إلى تطبيق أكثر
وضوحاً وموثوقية في التعامل مع الحالات المختلفة.
